# Numa for iPhone, iPad and Mac — rawler relink kits

Numa for Apple platforms includes [rawler](https://github.com/dnglab/dnglab), which is licensed under the GNU Lesser General Public License 2.1. As that licence requires, each release of Numa for Apple platforms has a **relink kit** here: rawler's complete source as used, and Numa's own code as object files, so that you can modify rawler and link it into Numa again.

Download the kit for your version from [Releases](../../releases). Each kit contains `RELINK.md` with the exact steps and tool versions. You need an Apple silicon Mac with Xcode and your own Apple developer account to sign the result.

Kits are kept here for at least three years after each release. Questions: support@numa.photo

Numa itself is not open source on Apple platforms. Numa for Linux is open source: [github.com/simmmmm/Numa](https://github.com/simmmmm/Numa).
